# Tanvi Jaware — Editorial Portfolio

A responsive editorial-style portfolio built with HTML, CSS and JavaScript, designed for free hosting on GitHub Pages.

## Files
- `index.html` — portfolio content
- `style.css` — design, layout and responsive styling
- `script.js` — scroll reveal interactions and back-to-top control
- `assets/tanvi-portrait.jpg` — supplied portrait photo

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload all files and the `assets` folder, preserving the folder structure.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Wait for the deployment and open the published URL.

Project links are currently set to the GitHub repositories in the HTML. Review them before publishing.
